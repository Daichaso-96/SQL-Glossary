SQL基礎解説 ― 基本情報技術者試験 対策ノート

SQLは「表（テーブル）に対して、列・行・並び・集計をどう操作するか」を命令する言語です。各句が表に対してどんな動作をするのか、関係代数の用語（射影・選択・結合）と対応させながら、商品表を使って確認します。

0. まず全体像 ― 各句が表に対して行う動作

SQLの句 表に対する動作 関係代数での呼び方
SELECT 列名必要な列だけを取り出す（縦に切る）射影（projection）
WHERE 条件条件に合う行だけを取り出す（横に切る）選択（selection）
FROM 表名操作の対象となる表を指定する―
JOIN ～ ON複数の表を共通の列でつなぐ結合（join）
GROUP BY 列名同じ値の行をまとめて集計の単位にするグループ化
HAVING 条件グループ化した結果に条件をかける―
ORDER BY 列名結果を指定した列で並べ替える整列（ソート）
覚え方：「SELECT は縦（列）を切る＝射影」「WHERE は横（行）を切る＝選択」。この2つの対応は試験で頻出です。

SELECT 商品名, 単価 FROM 商品表
動作（射影）：商品表から「商品名」と「単価」の列だけを縦に取り出します。行はすべて残ります。

全列を取り出すには SELECT * FROM 商品表 のように「*（アスタリスク）」を使います。

3. WHERE ― 条件で行を絞る（選択）

SELECT 商品名, 単価 FROM 商品表 WHERE 単価 >= 120
動作（選択）：「単価が120以上」という条件に合う行だけを横に取り出します。

■ 結果

商品名 単価

キャベツ200

4. ORDER BY ― 並べ替える（整列）

SELECT 商品名, 単価 FROM 商品表 ORDER BY 単価 DESC
動作（整列）：結果を単価の降順（大きい順）に並べ替えます。ASC＝昇順（小さい順、既定）、DESC＝降順（大きい順）。

■ 結果

商品名 単価
キャベツ200
りんご150
バナナ120
みかん100
にんじん80

5. GROUP BY と集約関数 ― グループごとに集計する

集約関数は「複数の行を1つの値にまとめる」関数です。

関数 意味
COUNT(*)行数を数える
SUM(列)合計
AVG(列)平均
MAX(列) / MIN(列)最大値 / 最小値
SELECT 分類, COUNT(*) AS 件数, AVG(単価) AS 平均単価 FROM 商品表 GROUP BY 分類
動作（グループ化＋集計）：「分類」が同じ行をまとめて1グループにし、グループごとに件数と平均単価を計算します。AS は列に別名をつける指定です。

■ 結果

分類 件数 平均単価
果物3123.3
野菜2140.0
果物＝(150+100+120)÷3＝123.3、野菜＝(200+80)÷2＝140.0。
注意：GROUP BY を使うとき、SELECT に書ける列は「グループ化した列」と「集約関数」だけです。

6. HAVING ― グループ化した結果に条件をかける

SELECT 分類, AVG(単価) AS 平均単価 FROM 商品表 GROUP BY 分類 HAVING AVG(単価) >= 130
動作：グループ化して平均単価を求めた後、平均単価が130以上のグループだけを残します。

■ 結果

分類 平均単価
野菜140.0
WHERE と HAVING の違い（頻出）：
・WHERE … グループ化の前に「行」を絞る（集約関数は使えない）
・HAVING … グループ化の後に「グループ」を絞る（集約関数が使える）

7. DISTINCT ― 重複を取り除く

SELECT DISTINCT 分類 FROM 商品表
動作：取り出した結果から重複した行を1つにまとめます。

■ 結果

分類
果物
野菜

8. JOIN ― 2つの表を結合する

もう1つ「売上表」があるとします（商品コードで商品表とつながります）。

■ 売上表

売上番号 商品コード 数量
1S0013
2S0032
3S0011
4S0055
SELECT 売上表.売上番号, 商品表.商品名, 売上表.数量 FROM 商品表 INNER JOIN 売上表 ON 商品表.商品コード = 売上表.商品コード
動作（結合）：商品コードが一致する行どうしをつなぎ、1つの表にします。これで売上に商品名を組み合わせて表示できます。INNER JOIN は両方の表で一致する行だけを残します。

■ 結果

売上番号 商品名 数量
1りんご3
2キャベツ2
3りんご1
4バナナ5
列名がどちらの表のものか区別するため 表名.列名 と書きます。S002・S004（みかん・にんじん）は売上が無いので INNER JOIN の結果には現れません。

9. 全部入りの例（記述順と実行順）

SELECT 分類, AVG(単価) AS 平均単価 FROM 商品表 WHERE 単価 >= 100 GROUP BY 分類 HAVING COUNT(*) >= 2 ORDER BY 平均単価 DESC
書く順番：SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY
実際に処理される順番：FROM →（JOIN）→ WHERE（行を選択）→ GROUP BY（集計）→ HAVING（グループを絞る）→ SELECT（列を射影）→ ORDER BY（整列）
※「WHERE で行を絞ってから集計し、HAVING で集計結果を絞り、最後に並べ替える」という流れを押さえておくと、出題パターンに対応しやすいです。
